US-002 — Link Session to Project
1
App.xaml.cs Presentation
├─ → SessionService.LinkSessionToProjectAsync(sessionId, projectId)
│ ├─ loads session via ISessionRepository.GetByIdAsync
│ ├─ (cond) session not found → throws DomainNotFoundException

│ │ └─ (cond) already linked → throws InvalidOperationException
