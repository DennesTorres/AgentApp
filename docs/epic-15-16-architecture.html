  ChatViewModel  ChatPresenter  │  ChatOrchestrator.SendAsync                             │ Azure AI
  ──────────────────────────────────────────────────────────────────────────────────────────────────────
        │               │          │                                                        │
        ─ SendAsync ────►          │                                                        │
                        ─ SendAsync ►                                                        │
                                   │  [1] history.Add(userMessage)                          │
                                   │                                                        │
                                   │  [2] build AIFunction tools                           │
                                   │      ┌─────────────────────────────────────────────┐  │
                                   │      │ read_file  write_file  list_directory       │  │
                                   │      │ each wrapper registers a closure that will:  │  │
                                   │      │   • FileSessionGate.CanRead/CanWrite()       │  │

                                   │      │   • return JSON result string to model      │  │
                                   │      └─────────────────────────────────────────────┘  │
                                   │                                                        │
                                   │  [3] CapabilityDispatcher.SendAsync(history, tools)   │
                                   │      ──────────────────────────────────────────────────►
                                   │          FunctionInvokingChatClient middleware         │
                                   │          ┌──────── tool call loop ────────────────┐  │
                                   │          │ model requests a tool                  │  │
                                   │          │ middleware intercepts mid-generation    │  │
                                   │          │ invokes the AIFunction closure [2]      │  │
                                   │          │ injects JSON result back into context   │  │
                                   │          │ model continues  ···  (0 to N times)   │  │
                                   │          └────────────────────────────────────────┘  │
                                   │      ◄── final text response ──────────────────────────
                                   │                                                        │

                                   │        for each command → find matching IActionProvider│
