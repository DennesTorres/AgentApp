Epics 15–17 — Runtime Message Flow

  Per-message workflow in ChatService.SendAsync (5 steps)
  ─────────────────────────────────────────────────────────────────────────────────────────────

  USER
    │
    │ types message
    ▼
  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  ChatViewModel  (UI layer)                                                               │
  │  ─────────────────────────────────────────────────────────────────────────────────────── │
  │  SendMessageAsync()                                                                      │
  │    • appends user bubble to Messages list                                                │
  │    • calls ChatService.SendAsync(text)                                                   │
  │    • dispatches visible commands (ReadFile, WriteFile, FolderSelect…)                   │
  │    • appends assistant bubble to Messages list                                           │
  │                                                                                          │
  │  ConfirmProjectAsync() / InitializeAsync()                                               │
  │    • calls IAgentContextService.SetProject(project, agentPath, codePath)                │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
    │
    │ SendAsync(userMessage)
    ▼
  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  ChatService  (Application layer)                                                        │
  │  ─────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                          │
  │  Step 1 ── Assemble system message                                                       │
  │    context = IAgentContextService.GetCurrent()                 ◄─── reads AgentContext   │
  │    systemMessage = providers                                                             │
  │                      .Where(p ⇒ p.IsApplicable(context))                                 │
  │                      .Select(p ⇒ p.GetSection(context))                                  │
  │                      .Join("\n\n")                                                       │
  │                                                                                          │
  │  Step 2 ── Model call                                                                    │
  │    payload = { history: [...], systemMessage: "..." }                                    │
  │    response = OrchestratorPipeline.SendAsync(ModelCall, payload)                         │
  │                                                                                          │
  │  Step 3 ── Parse commands                                                                │
  │    (displayText, commands) = ChatCommandParser.Parse(rawText)                            │
  │                                                                                          │
  │  Step 4 ── Detect STATE_TRANSITION  (internal — never returned to VM)                   │
  │    if StateTransitionCommand found:                                                      │
  │      IAgentContextService.UpdateConversationState(mode)         ─────► updates context   │
  │    filter StateTransitionCommand out of result                                           │
  │                                                                                          │
  │  Step 5 ── Return to ViewModel                                                           │
  │    return ChatServiceResult(displayText, visibleCommands)                                │
  │                                                                                          │

  STATE_TRANSITION loop (Step 4):
  ──────────────────────────────────────────────────────────────────────────────────────────
  Model response may contain: "... [STATE_TRANSITION:{"mode":"implementing"}] ..."
    → ChatCommandParser extracts StateTransitionCommand("implementing")
    → ChatService detects it, calls IAgentContextService.UpdateConversationState
    → AgentContext.ConversationState updated to ConversationState.FromMode("implementing")
    → StateTransitionCommand filtered out — NOT returned to ChatViewModel
    → Next message: ExecutionStateProvider.GetSection() returns "implementing"
  ──────────────────────────────────────────────────────────────────────────────────────────


  Command dispatch — after Step 5, ChatViewModel handles each visible command:
  ──────────────────────────────────────────────────────────────────────────────────────────

  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  ChatViewModel.HandleCommandAsync                                                        │
  │  ─────────────────────────────────────────────────────────────────────────────────────── │
  │                                                                                          │
  │  Interactive commands (shown as UI panels — user decides):                              │
  │    [FOLDER_SELECT]         → OS folder dialog → path injected back to ChatService        │
  │    [PROJECT_CONFIRM]       → confirm panel → user clicks OK:                             │
  │                                  ProjectService.CreateProjectAsync()                     │
  │                                  ScaffoldService.CreateScaffoldAsync()                   │
  │                                  IAgentContextService.SetProject(project, paths)         │
  │    [PATH_PERMISSION_REQUEST]→ permission panel → user approves:                         │
  │                                  FileSessionGate.GrantReadAccess(path)                  │
  │                                                                                          │
  │  Tool commands (executed silently — result injected back into conversation):            │
  │    [READ_FILE]  ──┐                                                                      │
  │    [WRITE_FILE] ──┤──► FileSessionGate.CanRead / CanWrite(path) ?                      │
  │    [LIST_DIR]   ──┘         No  → emit PathPermissionRequestCommand (interactive above) │
  │                             Yes → OrchestratorPipeline → file provider → result         │
  │                                   → ChatService.SendAsync (inject tool result)           │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
    │ tool commands (allowed path)
    ▼
  ┌───────────────────────────────────────────────┐
  │  FileSessionGate  (Infrastructure)            │
  │  ─────────────────────────────────────────── │
  │  Roots:  AgentFolderPath                      │
  │          CodeFolderPath                       │
  │  CanRead / CanWrite → path within roots?      │
  │  GrantReadAccess(path) → user-approved extras │
  └───────────────────────────────────────────────┘
    │ → OrchestratorPipeline routes to:
    ▼
  ┌──────────────────────────────────────────────────────────────────────────────────────────┐
  │  File Providers  (Infrastructure)                                                        │
  │  ─────────────────────────────────────────────────────────────────────────────────────── │
  │  FileReadProvider       ProviderCapability.FileRead   → reads file → string result       │
  │  FileWriteProvider      ProviderCapability.FileWrite  → writes content to path           │
  │  DirectoryListProvider  ProviderCapability.DirList    → lists entries with metadata      │
  │                                                                                          │
  │  Result returned to ChatViewModel → injected back as next ChatService.SendAsync call     │
  └──────────────────────────────────────────────────────────────────────────────────────────┘
