Message Flow & Command Dispatch

  ChatViewModel     ChatPresenter                        ChatOrchestrator

  ─── SendAsync ────────────────────────────────────────────────────────────────►
                                               build AIFunction tools (read_file,
                                               write_file, list_directory)
                                               ─── model call (with tools) ─────►
                                                   model may call tools N times
                                                   ↕ FunctionInvokingChatClient
                                                   loop until final text response
                                               ◄── final text ──────────────────
                                               ResponsePreparationService.Prepare()
                                                 → strip markers → clean text
                                                 → extract ChatCommands
                                               ActionProviderRegistry.DispatchAsync()
                                                 → handle orchestrator commands
                                                 → return unhandled to ViewModel
  ◄── ChatServiceResult { DisplayText, UnhandledCommands } ─────────────────────

  on each unhandled command:

    FolderSelectCommand     ──► dialog (UI) ──► HandleFolderSelectedAsync(path) ────►
    ProjectConfirmCommand   ──► show confirm UI
      user confirms        ──► ConfirmProjectAsync(cmd) ───────────────────────────►
                           ◄── (projectName, message) ──────────────────────────────
    PathPermissionRequest   ──► show permission UI
      user approves        ──► GrantPermissionAsync(path) ─────────────────────────►
                               gate.GrantReadAccess · PATH_ACCESS_GRANTED — internal
                           ◄── ChatServiceResult ───────────────────────────────────

  note: read_file / write_file / list_directory are no longer ChatCommands —
  they are resolved inside the model call loop via native tool-calling

  blue = UI · yellow = Application · orange = Infrastructure · grey = External
