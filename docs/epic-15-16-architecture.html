Key Runtime Flows

① Send Message — 5-step ChatService Workflow (US-135b)
① AgentContextService.GetCurrent() → providers filter + build systemMessage
② OrchestratorPipeline → AzureChatClientProvider
Azure / Kimi-K2.5 systemMessage + history → response
③ ChatCommandParser.Parse → DisplayText + Commands[]
④ detect StateTransitionCommand → AgentContext.UpdateConversationState
StateTransitionCommand filtered out of result
⑤ ChatViewModel.HandleCommandAsync visible commands only
② STATE_TRANSITION Loop (US-135b)
[STATE_TRANSITION:{"mode":"implementing"}]
↓ ChatCommandParser → StateTransitionCommand("implementing")
↓ Step 4
IAgentContextService .UpdateConversationState(FromMode("implementing"))
↓ AgentContext.ConversationState = "implementing"
↓ next message (Step 1)
ExecutionStateProvider.GetSection → "mode: implementing" in system msg
③ Project Confirm → AgentContext Updated (US-153 + US-135b)
[PROJECT_CONFIRM:{"name":"MyApp","intent":"..."}]
↓ Confirm panel shown user clicks Confirm
ProjectService.CreateProjectAsync → Project persisted
ScaffoldService.CreateScaffoldAsync mkdir agent + code folders
FileSessionGate.SetProjectRoots + AgentContextService.SetProject
↓ next message (Step 1)
ActiveProjectProvider IsApplicable → true → project name + paths in system msg
④ File Read + Permission Gate (US-159 + US-163)
[READ_FILE:{"path":"C:/code/..."}]
↓ ChatCommandParser → ReadFileCommand(path)
FileSessionGate.CanRead(path)?
No → [PATH_PERMISSION_REQUEST:{"path":"...","reason":"..."}]
Yes → FileReadProvider → ChatService.SendAsync(result)
Command Protocol — Embedded JSON Markers (ChatCommandParser)
[FOLDER_SELECT:{"reason":"<why>"}] Model requests OS folder browser US-155
[PROJECT_CONFIRM:{"name":"<n>","intent":"<i>"}] Model proposes project → Confirm/Cancel panel US-153
[READ_FILE:{"path":"<p>"}] Model requests file content (gate checked) US-159
[WRITE_FILE:{"path":"<p>","content":"<c>"}] Model writes file (brace-depth extraction) US-160
[LIST_DIR:{"path":"<p>"}] Model lists directory entries US-162
[PATH_PERMISSION_REQUEST:{"path":"<p>","reason":"<r>"}] Model requests read access to path outside roots US-163
[STATE_TRANSITION:{"mode":"<m>"}] Model signals conversation mode change — internal, never shown to user US-135b
