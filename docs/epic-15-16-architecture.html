Command Dispatch

  ChatViewModel                                    ChatOrchestrator

  ─── SendAsync(text) ──────────────────────────────────────────────────────────►
  ◄── ChatServiceResult { DisplayText, Commands } ──────────────────────────────

  on each command returned:

    FolderSelectCommand     ──► dialog (UI) ──► HandleFolderSelectedAsync(path) ─────►
    ProjectConfirmCommand   ──► show confirm UI
      user confirms        ──► ConfirmProjectAsync(cmd) ──────────────────────────────►
                           ◄── (projectName, message) ───────────────────────────────
    ReadFile / WriteFile /  
      ListDirectory         ──► ExecuteFileCommandAsync(cmd) ──────────────────────────►
                               gate check · file op · follow-up model call — all internal
                           ◄── ChatServiceResult ────────────────────────────────────
    PathPermissionRequest   ──► show permission UI
      user approves        ──► GrantPermissionAsync(path) ────────────────────────────►
                               gate.GrantReadAccess · PATH_ACCESS_GRANTED — all internal
                           ◄── ChatServiceResult ────────────────────────────────────

  blue = UI · yellow = Application · orange = Infrastructure · grey = External
