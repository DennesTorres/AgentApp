Command Dispatch — ViewModel ↔ Orchestrator

  ChatViewModel                          ChatOrchestrator

  SendMessageAsync()
    │─── SendAsync(text) ──────────────────────────────────────────────────────►│
    │◄─── ChatServiceResult {DisplayText, Commands} ───────────────────────────│
    │                                                                            │
    │  HandleCommandAsync(cmd):                                                  │
    │    FolderSelectCommand        → dialog → HandleFolderSelectedAsync(path) ─►│
    │    ProjectConfirmCommand      → show UI (HasProjectConfirmPending=true)    │
    │    ReadFile/WriteFile/ListDir → ExecuteFileCommandAsync(cmd) ─────────────►│
    │                                 gate check + file op + follow-up SendAsync │
    │                               ◄─ ChatServiceResult ───────────────────────│
    │    PathPermissionRequest      → show UI (HasPermissionRequestPending=true) │

  ConfirmProjectAsync()   [user click]
    │─── ConfirmProjectAsync(cmd) ────────────────────────────────────────────►│
    │    [creates project, scaffold, sets gate roots internally]                │
    │◄─── (projectName, successMessage) ────────────────────────────────────────│

  ApprovePermissionAsync() [user click]
    │─── GrantPermissionAsync(path) ──────────────────────────────────────────►│
    │    [grants access, sends PATH_ACCESS_GRANTED to model internally]         │
    │◄─── ChatServiceResult ────────────────────────────────────────────────────│

  Legend:
    blue  = UI layer (ViewModels, XAML)
    yellow= Application layer (orchestrators, services, parsers)
    orange= Infrastructure layer (providers, repositories, file access)
    grey  = External systems
